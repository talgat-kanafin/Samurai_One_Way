# Samurai Desktop

A desktop application for idea and project lifecycle management, powered by AI.

## Overview

Samurai Desktop guides your ideas through three stages of development:

- **Seed** — Capture raw ideas, research, and initial concepts through text and AI-assisted chat
- **Tree** — Develop confirmed ideas into structured projects with financial tracking and release planning
- **Sprout** — Validate MVPs, run ecosystem checks, and prepare for launch

Each stage has dedicated screens and an integrated AI chat to help you move forward with clarity.

## Features

- AI-powered idea capture and research assistant
- Project lifecycle tracking: Seed → Tree → Sprout
- Financial planning widget
- MVP validation workflow
- Ecosystem release management
- Settings and API key management

## Tech Stack

- Python
- Desktop UI framework
- AI integration via API
